# rta-demo

## Setup
Add a `.env` file to the root of the project with the following content:

```bash
OPENAI_API_KEY=sk-...
OPENAI_API_BASE=https://api.openai.com/v1
```

## Run

```bash
streamlit run Welcome.py
```
